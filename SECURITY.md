# Security policy

ont-offload moves clinical sequencing data. Please report vulnerabilities privately.

- Use GitHub's **Report a vulnerability** (Security tab, private advisory) on `esteinig/ont-offload`.
- Do not open public issues for security problems or include patient data in any report.
- We aim to acknowledge reports within 5 working days and to agree a disclosure timeline with you.

Supported versions: the latest release on `main`.
